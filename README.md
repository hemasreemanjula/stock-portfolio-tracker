Stock Portfolio Tracker

Overview

Stock Portfolio Tracker is a simple Python project that calculates the total investment value of a stock portfolio based on user-input stock names and quantities.

The program uses a predefined dictionary of stock prices and performs basic calculations to determine the total investment value. It also provides an option to save the result in a text file.

Features

- User-friendly console interface
- Predefined stock prices using a dictionary
- Accepts stock names and quantities as input
- Calculates individual stock investment values
- Calculates total portfolio investment value
- Option to save results to a text file
- Demonstrates Python dictionaries, loops, conditional statements, and file handling

Technologies Used

- Python 3

How to Run

1. Clone the repository:
   
   git clone https://github.com/your-username/stock-portfolio-tracker.git

2. Navigate to the project folder:
   
   cd stock-portfolio-tracker

3. Run the program:
   
   python stock_portfolio_tracker.py
